# Entre sombras e fatos

Experiência digital de um presente-enigma sobre aparências, fatos e uma fotografia que ainda não existe.

## Publicação

O projeto usa Vercel Blob para manter o cronômetro e a fotografia definitiva sincronizados entre aparelhos. Vincule um Blob Store ao projeto no Vercel para disponibilizar `BLOB_READ_WRITE_TOKEN` antes da publicação.

A montagem original está em `montagem-real.jpeg`. Os arquivos antigos que chegaram corrompidos não são usados pelo site.

Os áudios locais devem ser adicionados como `audio/interstellar.mp3` e `audio/quase-sem-querer.mp3`. Servir os arquivos pelo próprio site evita bloqueios de incorporação do YouTube; use apenas cópias que você tenha autorização para hospedar.
